# HTML Runner

Open the GitHub Pages URL and drop an `.html` file onto the page. To load local images, stylesheets, scripts, fonts, or other files referenced by the HTML, drop the page's folder so its file structure is preserved. Use the single floating control to enter fullscreen.

The page displays HTML in a sandboxed browser iframe. It uses the browser's normal rendering and graphics acceleration; it cannot provide native application performance or access browser-blocked system features.

## GitHub Pages

The site is published from the `main` branch at the repository root.
